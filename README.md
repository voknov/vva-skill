# VVA 视频导演 Skill

这是 VOKWA 官方维护的 VVA 视频导演公开 Skill，供 Kimi Work Plugin Builder 和其他兼容
`SKILL.md` 的 Agent 导入。

VVA 位于故事创作之后、视频生成之前：把用户已有的故事构想、大纲或剧本整理为角色、场景、
道具、声音、分集、段落和镜头，并安全同步到 [VVA 创作台](https://video.pictech.top)。

## 在 Kimi Work 中安装

1. 将 Kimi Work 更新到最新版。
2. 在对话框输入 `/`，选择 **Plugin Builder**。
3. 让 Plugin Builder 导入本仓库：`https://github.com/voknov/vva-skill`。
4. 进入 **插件 → 个人**，找到“VVA 视频导演”，点击“＋”安装。
5. 在新任务中说：“使用 VVA，检查我的登录状态。”首次使用时按提示完成 VVA 网页授权。

不需要配置 MCP，也不要向 Agent 提供密码、访问令牌或 API Key。VVA Skill 的创作同步操作
不会自行执行付费生成。

其他 Agent 的安装包和详细说明见 [VVA Skill 页面](https://video.pictech.top/skill)。
